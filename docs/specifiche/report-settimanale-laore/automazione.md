# REPORT SETTIMANALE - LAORE: automazione PowerPoint

**Non c'è.** Nessuna delle 34 automazioni di Qlik Cloud usa l'app REPORT SETTIMANALE - LAORE (controllato il 14/11/2026
leggendo i blocchi di tutte le automazioni). Il report si guarda nell'app (17 fogli) e, se serve un file, si esporta a mano.
L'app non ha pianificazione: ultimo ricarico **31/07/2026** (a mano).

Per il portale: è un report **separato** dal settimanale (decisione del proprietario, 14/11). Proposta: stessa pagina-report
con il suo menu, e, se lo si vuole, un PowerPoint con il generatore comune (copertina + i 17 fogli nell'ordine di
struttura.md), nome «{AAMMGG} - {Azienda} - Report settimanale Laore.pptx». Da decidere con il proprietario.
