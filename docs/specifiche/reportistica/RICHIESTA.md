# Reportistica: struttura decisa dal proprietario (27/11/2026, dall'app)

Tutti i report sotto un solo punto di menù «Report» (Reportistica):

- Analisi suolo
  - Inserimento analisi suolo
  - Report analisi suolo
- Maturazione uve
  - Inserimento analisi uve
  - Report maturazione uve
- Meteo
  - Modifica dati meteo, inserimento stazioni meteo, monitoraggio flussi di dati in entrata
  - Report meteo
- Indice Bigot
  - Inserimento obiettivi parametri Indice Bigot
  - Dashboard live: a che punto sto durante la stagione con l'indice e i vari parametri
  - Report Indice Bigot
- Report settimanale
  - Backend: scegliere quali KPI, grafici ecc. nascondere dal report finale; vedere tutto il flusso di dati dietro
    a quello che si vede, fino al rilievo iniziale
  - Report settimanale
- Report metà stagione
  - Backend (come sopra)
  - Report metà stagione
- Report fine stagione
  - Backend (come sopra)
  - Report fine stagione

Chi vede cosa:
- Consulente Perleuve (interno): frontend e backend.
- Cliente (azienda in consulenza): solo il frontend, cioè il report fatto per lui dal consulente Perleuve.
- Abbonato: tutto (frontend e backend).

«Tutto il backend va progettato.»
